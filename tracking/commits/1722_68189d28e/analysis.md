## 总体目的

修复 1.8.0 发版说明的 Markdown 格式问题。在提交 1717 中添加了 1.8.0 的发版说明，但发版说明正文与后续列表之间缺少一个空行，导致 Markdown 渲染时列表项可能不会被正确渲染为列表。

Markdown 规范要求列表前必须有一个空行才能正确渲染为列表，否则列表项会被视为前一段落的延续。此提交在发版说明描述行和第一个列表项之间添加了一个空行。

## 如何达成设计目的

在 `site/docs/releases.md` 中 1.8.0 发版说明的描述行和列表之间添加一个空行。

## 修改详情

### `site/docs/releases.md`（修改, +1 line）

**修改目的**：修复 1.8.0 发版说明的 Markdown 格式。

**工作逻辑**：在 "The 1.8.0 release contains bug fixes and new features..." 这一行之后添加一个空行，使其后的 "* Deprecation / End of Support" 列表项能正确渲染为无序列表。

## 小结

- **成效**：1.8.0 发版说明在网站上正确渲染，列表项显示为列表格式。
- **影响范围**：仅影响网站文档格式，不影响内容。
- **回迁到 1.4.x 的注意事项**：不建议回迁。这是 1.8.0 发版说明的格式修复，与 1.4.x 分支无关。此提交依赖前置提交 1717（添加 1.8.0 发版说明）。
