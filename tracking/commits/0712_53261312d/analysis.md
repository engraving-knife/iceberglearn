## 总体目的

本提交更新 GitHub Bug 报告 Issue 模板，把版本下拉选项中的"最新发布"从 1.5.0 切换为 1.5.1，并将 1.5.0 降级为普通历史版本保留在列表中。

Iceberg 在发布新版本（1.5.1）后，社区需要及时把 Issue 模板中的"latest release"标记更新到新版本，这样用户在提交 Bug 报告时能选择正确的当前版本，方便维护者根据版本号快速定位问题、复现 Bug、判断是否为已修复的回归。若不及时更新，用户可能误选 1.5.0 作为"最新版本"，导致维护者基于错误的版本假设进行排查。

## 如何达成设计目的

策略简单直接：在 `.github/ISSUE_TEMPLATE/iceberg_bug_report.yml` 的版本下拉选项（options）中，把第一项 `"1.5.0 (latest release)"` 替换为两项：
- `"1.5.1 (latest release)"`（新最新版本，排在第一位）
- `"1.5.0"`（原最新版本降级为普通选项，去掉 "(latest release)" 标记）

这是 Iceberg 每次发版后的常规维护操作，遵循既有的版本递进模式。

## 修改详情

### `.github/ISSUE_TEMPLATE/iceberg_bug_report.yml`
**修改目的**：将 Bug 报告模板的版本下拉项更新为 1.5.1 作为最新版本。
**工作逻辑**：

修改前的版本选项片段：
```yaml
options:
  - "1.5.0 (latest release)"
  - "1.4.3"
  - "1.4.2"
  - "1.4.1"
```

修改后：
```yaml
options:
  - "1.5.1 (latest release)"
  - "1.5.0"
  - "1.4.3"
  - "1.4.2"
  - "1.4.1"
```

变化点：
- 新增 `"1.5.1 (latest release)"` 作为首选项（默认选中第一项）。
- 原 `"1.5.0 (latest release)"` 改为 `"1.5.0"`，去掉 "(latest release)" 后缀，降级为历史版本。
- 其余 1.4.x 版本保持不变。

## 小结
- **成效**：成功将 Issue 模板的版本选项更新到 1.5.1，与最新发布版本同步。
- **影响范围**：仅影响 GitHub Issue 模板配置，不影响任何运行时代码。
- **回迁到 1.4.x 的注意事项**：1.4.x 分支的 Issue 模板应保持 1.4.x 系列的版本选项，不应 cherry-pick 此 1.5.1 更新（1.4.x 分支应维持自己的版本序列）。此改动属于 main 分支的发版维护，与 1.4.x 回迁无关。
