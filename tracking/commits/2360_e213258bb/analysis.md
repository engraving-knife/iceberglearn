## 总体目的

这个提交更新 Iceberg 官方文档站点以反映 1.9.2 版本的发布。Apache Iceberg 1.9.2 于 2025 年 7 月 16 日发布，是一个 bug 修复版本。本提交将发布说明、版本号和导航配置更新到 1.9.2。

Iceberg 的文档站点使用 mkdocs 构建，维护着版本发布说明页面（`releases.md`）、全局版本变量（`mkdocs.yml`）和导航配置（`nav.yml`）。每次发布新版本时需要更新这些文件以反映新版本信息。

## 如何达成设计目的

1. 在发布说明页面新增 1.9.2 的发布记录。
2. 将站点全局版本变量从 1.9.1 更新为 1.9.2。
3. 在导航配置中添加 1.9.2 版本入口。

## 修改详情

### `site/docs/releases.md` (+13/-3 lines)

**修改目的**：添加 1.9.2 发布说明并调整结构。

**工作逻辑**：在 1.9.1 发布说明之前新增 1.9.2 的发布记录段落，包含发布日期（Jul 16, 2025）、说明（bug 修复版本）和 GitHub release 链接，以及 Core 部分的修复条目（停止在 502/504 错误上重试以避免自冲突导致的表损坏）。同时将 `## Past releases` 标题移至 1.9.1 之前，使 1.9.2 成为当前最新发布。

### `site/mkdocs.yml` (+1/-1 lines)

**修改目的**：更新全局版本变量。

**工作逻辑**：将 `icebergVersion: '1.9.1'` 改为 `icebergVersion: '1.9.2'`，使站点各处引用的版本号更新为最新发布版本。

### `site/nav.yml` (+1/-0 lines)

**修改目的**：在导航中添加 1.9.2 版本入口。

**工作逻辑**：在 Docs 导航的 `latest` 之后、`1.9.1` 之前添加 `1.9.2: '!include docs/docs/1.9.2/mkdocs.yml'`，使文档站点导航中出现 1.9.2 版本的文档入口。

## 总结

该提交更新了 Iceberg 文档站点以反映 1.9.2 版本发布，包括新增发布说明、更新全局版本号和导航配置。这是发布流程的标准文档更新操作，纯文档变更，无代码改动。
