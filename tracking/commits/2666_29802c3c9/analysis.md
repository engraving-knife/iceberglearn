## 总体目的

本提交将 Apache Hadoop 依赖从 3.4.1 升级到 3.4.2。这是一个维护性的小版本升级，Hadoop 3.4.2 是 3.4.x 系列的补丁版本，通常包含 Bug 修复、安全补丁和小的改进，不涉及破坏性 API 变更。

Iceberg 依赖 Hadoop 提供文件系统抽象（HDFS、本地文件系统等）和相关工具。保持 Hadoop 依赖的最新状态有助于获取最新的 Bug 修复和安全补丁，提升稳定性和安全性。

## 如何达成设计目的

通过修改 Gradle 版本目录文件中 Hadoop 的版本引用，将 `hadoop3` 从 `3.4.1` 更新为 `3.4.2`。

## 修改详情

### `gradle/libs.versions.toml` (+1/-1 lines)

**修改目的**：升级 Hadoop 版本。

**工作逻辑**：将 `hadoop3 = "3.4.1"` 改为 `hadoop3 = "3.4.2"`。该版本变量被所有 `hadoop3-*` 依赖库引用（如 `hadoop3-client`、`hadoop3-common`、`hadoop3-hdfs` 等），因此一处修改即可更新所有 Hadoop 相关依赖。

## 总结

本提交将 Hadoop 依赖从 3.4.1 升级到 3.4.2，这是一个小版本补丁升级，包含 Bug 修复和安全改进。修改仅涉及版本目录中一行版本号变更，所有 Hadoop 相关依赖会自动更新到新版本。这类依赖升级有助于保持项目的安全性和稳定性。
