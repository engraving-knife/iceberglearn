## 总体目的

这个提交把 GitHub Issue 模板中的版本下拉选项从 `1.3.1 (latest release)` 调整为 `1.4.0 (latest release)`，并把 `1.3.1` 降级为普通选项，使其与新发布的 1.4.0 版本同步。

Iceberg 在 `.github/ISSUE_TEMPLATE/iceberg_bug_report.yml` 中定义了 bug 报告模板，要求报告者选择所使用的 Iceberg 版本。模板中维护了一个版本下拉列表，并把"最新发布版本"标注出来作为默认推荐选项。在 1.4.0 发布之前，最新版本是 1.3.1，所以列表顶部是 `1.3.1 (latest release)`，下方的 1.3.0、1.2.1、1.2.0 等是历史版本。

1.4.0 在 2023 年 10 月初发布后，社区需要收集针对 1.4.0 的 bug 报告，因此模板必须把 1.4.0 加入选项并标记为最新版，引导用户在报告问题时优先选择 1.4.0。同时 1.3.1 仍然是受支持版本（用户可能仍在使用），所以不能直接删除，而是去掉 `(latest release)` 标注，作为普通选项保留在列表中。这是每次新版本发布后的标准维护动作，与提交 0016（revapi 基线推进）同属 1.4.0 发版配套变更，二者提交时间相隔仅 19 秒。

## 如何达成设计目的

设计思路是直接编辑 bug 报告模板 YAML 中的版本 `options` 列表：将原来标注为最新的 `1.3.1 (latest release)` 拆为两行——新增 `1.4.0 (latest release)` 置于列表顶部，把 `1.3.1` 作为普通选项跟在后面，其余历史版本选项（1.3.0、1.2.1、1.2.0 等）保持不变。

## 修改详情

### `.github/ISSUE_TEMPLATE/iceberg_bug_report.yml`

**修改目的**：将 bug 报告模板的版本选项更新为以 1.4.0 为最新版，1.3.1 降级为普通选项。

**工作逻辑**：改动位于模板 `body` 中版本选择控件的 `options` 数组。修改前为：

```yaml
options:
  - "1.3.1 (latest release)"
  - "1.3.0"
  - "1.2.1"
  - "1.2.0"
```

修改后为：

```yaml
options:
  - "1.4.0 (latest release)"
  - "1.3.1"
  - "1.3.0"
  - "1.2.1"
  - "1.2.0"
```

即把 1.3.1 的 `(latest release)` 标注去掉并在其上方新增 1.4.0 作为最新版选项。GitHub 表单会将列表第一项作为默认选中项，因此新模板会默认引导用户选择 1.4.0。

## 小结

该提交把 bug 报告模板的版本下拉列表更新为以 1.4.0 为最新发布版本、1.3.1 降级为普通选项，确保 1.4.0 发布后社区能正确收集针对该版本的 bug 报告。
