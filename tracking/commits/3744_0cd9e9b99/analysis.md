## 总体目的

本提交将 Revapi（API 二进制兼容性检查工具）的比对基线版本从 1.10.0 更新为 1.11.0。

Revapi 用于在 CI 中检测 Iceberg 各模块的公共 API 是否发生不兼容的破坏性变更（如删除方法、修改签名等）。它通过将当前构建的 API 与一个"旧版本"的 API 进行对比来发现潜在的不兼容变更。随着 Iceberg 1.11.0 版本的发布，API 基线应当更新为 1.11.0，使得后续开发（针对 1.12.0 或更新版本）的 API 变更都是相对于 1.11.0 进行比较，而非仍然相对于 1.10.0。这样可以确保基线反映最新的已发布 API 状态，避免 1.10.0 到 1.11.0 之间已经发生的（已接受的）API 变更被误报为破坏性变更。

## 如何达成设计目的

修改 `build.gradle` 中 Revapi 配置的 `oldVersion` 从 `"1.10.0"` 改为 `"1.11.0"`，使所有子项目的 Revapi 检查都以 1.11.0 作为比对基线。

## 修改详情

### `build.gradle` (+1/-1 lines)

**修改目的**：更新 Revapi API 兼容性检查的基线版本。

**工作逻辑**：
在 `subprojects` 块的 `revapi` 配置中，将 `oldVersion = "1.10.0"` 修改为 `oldVersion = "1.11.0"`：
```groovy
revapi {
  oldGroup = project.group
  oldName = project.name
  oldVersion = "1.11.0"  // 原为 "1.10.0"
}
```
这样 Revapi 会从 Maven 仓库解析对应项目 1.11.0 版本的 API 作为基线，与当前构建的 API 进行对比，检测不兼容变更。

## 总结

本提交将 Revapi API 二进制兼容性检查的基线版本从 1.10.0 更新为 1.11.0，使后续开发的 API 变更检查基于最新的已发布版本（1.11.0）。这是 1.11.0 版本发布后的配套构建配置更新，确保 API 兼容性检查的基线反映最新的已发布 API 状态，避免已接受的 1.10.0→1.11.0 间的 API 变更被误报为破坏性变更。改动仅涉及构建配置，不影响产品代码。
