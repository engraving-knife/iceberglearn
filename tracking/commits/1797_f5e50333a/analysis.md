## 总体目的

此提交用于更新 Iceberg 仓库的 GitHub Bug 报告模板，将可选的 Iceberg 版本列表同步到 1.8.1 发布后的状态。

1.8.1 于 2025 年 2 月 28 日发布，成为最新版本。Bug 报告模板中原先将 “1.8.0 (latest release)” 作为最新版本选项，发布 1.8.1 后需将最新版本标记转移到 1.8.1，同时保留 1.8.0 作为可选项，以便用户在报告 bug 时能准确选择自己使用的版本。这能提升 bug 报告的版本信息准确性，便于维护者分流与复现。

这是仓库基础设施（Issue 模板）类修改，不涉及代码逻辑。

## 如何达成设计目的

通过编辑 `.github/ISSUE_TEMPLATE/iceberg_bug_report.yml` 中版本下拉选项达成目标：将原 “1.8.0 (latest release)” 一行替换为两行——“1.8.1 (latest release)” 与 “1.8.0”，使 1.8.1 成为最新版本选项，1.8.0 降为普通可选项。其余版本选项（1.7.1、1.7.0、1.6.1 等）保持不变。

## 修改详情

### `.github/ISSUE_TEMPLATE/iceberg_bug_report.yml`（修改, +2/-1 lines）

**修改目的**：同步 bug 报告模板的 Iceberg 版本选项到 1.8.1 发布后的状态。

**工作逻辑**：模板中 `body` 下某一项的 `options` 列表，原内容为：

```yaml
options:
  - "1.8.0 (latest release)"
  - "1.7.1"
  - "1.7.0"
  - "1.6.1"
```

修改后为：

```yaml
options:
  - "1.8.1 (latest release)"
  - "1.8.0"
  - "1.7.1"
  - "1.7.0"
  - "1.6.1"
```

即把最新版本标记从 1.8.0 移到 1.8.1，并把 1.8.0 作为普通选项保留。用户提交 bug 时默认看到 1.8.1 为最新版本，便于选择正确版本。

## 小结

- **成效**：Bug 报告模板的版本选项与 1.8.1 发布同步，用户报告 bug 时能准确选择 1.8.1 或 1.8.0，提升 bug 报告版本信息的准确性。
- **影响范围**：仅影响 `.github/ISSUE_TEMPLATE/iceberg_bug_report.yml` 一个 GitHub Issue 模板文件，不涉及代码、构建或测试。
- **回迁到 1.4.x 的注意事项**：这是针对 1.8.1 发布的模板更新，**不建议回迁到 1.4.x 分支**。原因：1.4.x 分支的 bug 报告模板应反映 1.4.x 自身的版本组合，回迁 1.8.1 的选项会造成版本列表与 1.4.x 实际发布版本不符，反而误导用户。若 1.4.x 需要更新模板，应基于 1.4.x 的版本序列单独维护。
