## 总体目的

此提交为 Iceberg 1.9.1 版本发布更新项目网站文档。1.9.1 是一个 Bug 修复版本，发布于 2025 年 5 月 27 日。此提交在发布说明中添加 1.9.1 的条目，更新网站配置中的版本号，并在导航中添加 1.9.1 的文档链接。同时还为 1.9.0 版本添加了一个关于构建系统 Bug 的说明（1.9.0 通过 API 查询版本会返回 'unknown'，此问题在 1.9.1 中修复）。这是版本发布流程中网站更新的标准步骤。

## 如何达成设计目的

- 在 `releases.md` 中添加 1.9.1 的发布说明条目
- 将 "Past releases" 标题移到 1.9.0 之前，因为 1.9.1 现在是最新版本
- 为 1.9.0 添加构建系统 Bug 的说明
- 更新 `mkdocs.yml` 中的 `icebergVersion` 从 1.9.0 改为 1.9.1
- 在 `nav.yml` 中添加 1.9.1 的文档导航条目

## 修改详情

### `site/docs/releases.md` (修改, +20/-2 lines)

**修改目的**：添加 1.9.1 发布说明并调整文档结构。

**工作逻辑**：
- 在 1.9.0 发布说明之前添加 1.9.1 的发布说明，包含 API、Core 和依赖更新三类修复条目
- 将 "## Past releases" 标题从 1.8.1 之前移到 1.9.0 之前，使 1.9.1 成为当前最新版本
- 在 1.9.0 的说明中添加关于构建系统 Bug 的注意事项（版本查询返回 'unknown'）

### `site/mkdocs.yml` (修改, +1/-1 lines)

**修改目的**：更新网站配置中的 Iceberg 版本号。

**工作逻辑**：将 `extra.icebergVersion` 从 '1.9.0' 改为 '1.9.1'，使网站模板中使用该变量的地方显示正确版本。

### `site/nav.yml` (修改, +1/-0 lines)

**修改目的**：在网站导航中添加 1.9.1 文档链接。

**工作逻辑**：在 Docs 导航部分的 latest 和 1.9.0 之间添加 `1.9.1: '!include docs/docs/1.9.1/mkdocs.yml'` 条目。

## 总结

此提交为 Iceberg 1.9.1 版本发布更新了网站文档，包括添加发布说明、更新版本配置和导航链接。同时为 1.9.0 添加了构建系统 Bug 的说明。这是版本发布流程的标准网站更新步骤。
