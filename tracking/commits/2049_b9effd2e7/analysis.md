## 总体目的

Apache Iceberg 项目在发布 1.9.0 版本时，需要同步更新项目根目录下的 `doap.rdf` 文件，以反映最新的发布版本信息。DOAP（Description of a Project）文件是 Apache 软件基金会项目用于描述自身元数据的 RDF 文件，包含项目的名称、主页、描述、维护者、发布版本等信息，会被 Apache 项目站点（如 projects.apache.org）聚合展示。

此次更新将最新发布版本从 1.8.1 替换为 1.9.0，并将发布日期更新为 2025-04-28。这是 1.9.0 版本发布流程中的元数据维护步骤。

## 如何达成设计目的

通过修改 `doap.rdf` 文件中 `<release>` 节点下 `<Version>` 元素中的三个字段：
- `<name>`：版本显示名称
- `<created>`：版本发布日期
- `<revision>`：版本号字符串

将这三处从 `1.8.1` / `2025-02-28` 替换为 `1.9.0` / `2025-04-28`，使得 Apache 项目页面能够正确展示最新发布版本。

## 修改详情

### `doap.rdf` (修改, +3/-3 lines)

**修改目的**：将 DOAP 文件中记录的最新发布版本从 1.8.1 更新为 1.9.0。

**工作逻辑**：
DOAP RDF 文件使用 XML 格式描述 Apache 项目元数据。`<release>` 节点包含一个或多个 `<Version>` 元素，每个 `<Version>` 描述一次发布。本次修改仅替换了现有 `<Version>` 节点中的三个子元素值，未新增新的版本节点（即只保留最新版本而非追加历史版本），将版本名称、发布日期、版本号统一更新为 1.9.0 及其发布日期 2025-04-28。

## 总结

这是 1.9.0 版本发布过程中的一项元数据维护工作，通过更新 DOAP RDF 文件让 Apache 项目展示页面反映最新发布版本 1.9.0。修改范围极小（3 行替换），无功能影响。
