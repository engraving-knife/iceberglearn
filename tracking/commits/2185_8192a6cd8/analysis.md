## 总体目的

此提交将 Iceberg 的 Spark 3.5 模块所依赖的 Spark 版本从 3.5.5 升级到 3.5.6。Spark 3.5.6 是 Spark 3.5.x 系列的维护版本，包含 Bug 修复和改进。保持 Spark 依赖版本的及时更新有助于获取最新的修复和改进，确保 Iceberg 与 Spark 3.5 系列的最新版本兼容。从提交信息来看，开发过程中先使用了快照版本，后来切换到了正式发布的 Spark 3.5.6 版本。

## 如何达成设计目的

- 在 `gradle/libs.versions.toml` 中将 `spark35` 的版本从 `3.5.5` 更新为 `3.5.6`

## 修改详情

### `gradle/libs.versions.toml` (修改, +1/-1 lines)

**修改目的**：更新 Spark 3.5 的依赖版本号。

**工作逻辑**：将 `spark35 = "3.5.5"` 改为 `spark35 = "3.5.6"`，使 Spark 3.5 模块在构建时使用 Spark 3.5.6 版本。注意 Spark 3.4 和 Spark 4.0 的版本号保持不变（分别是 3.4.4 和 4.0.0）。

## 总结

此提交将 Iceberg Spark 3.5 模块的 Spark 依赖版本从 3.5.5 升级到 3.5.6，属于补丁版本升级。这是常规的依赖维护工作，确保 Iceberg 与 Spark 3.5 系列的最新维护版本兼容。
