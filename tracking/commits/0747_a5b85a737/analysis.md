## 总体目的

这是 1.5.2 版本发布配套的文档站点更新提交。Iceberg 官网（基于 MkDocs 构建）维护着多版本文档的导航与版本变量，每次发版后需要将站点指向新版本的文档源，并把新版本加入版本切换菜单。本提交将站点的 `icebergVersion` 变量从 `1.5.1` 更新为 `1.5.2`，并在导航配置中新增 1.5.2 文档入口。

## 如何达成设计目的

改动涉及站点配置的两个 YAML 文件：一是 `mkdocs.yml` 中的 `extra.icebergVersion` 变量，用于在页面中渲染当前版本号；二是 `nav.yml` 中的版本导航列表，新增 1.5.2 条目使其出现在版本切换菜单中。

## 修改详情

### `site/mkdocs.yml`

**修改目的**：将站点全局变量 `icebergVersion` 从 `1.5.1` 更新为 `1.5.2`。

**工作逻辑**：`extra` 段中的 `icebergVersion` 变量被站点模板引用，用于在文档页面展示当前 Iceberg 版本号。修改前为 `icebergVersion: '1.5.1'`，修改后为 `icebergVersion: '1.5.2'`。

### `site/nav.yml`

**修改目的**：在 Docs 版本导航列表中新增 1.5.2 文档入口。

**工作逻辑**：在 `Docs` 导航段中，于 `latest` 与 `1.5.1` 之间插入一行 `1.5.2: '!include docs/docs/1.5.2/mkdocs.yml'`，使 1.5.2 文档出现在版本切换菜单中。原有的 1.5.1、1.5.0、1.4.3 等历史版本条目保持不变。

## 小结

- **成效**：完成 1.5.2 发版的文档站点配置更新，使官网能正确展示 1.5.2 版本号并提供 1.5.2 文档入口。
- **影响范围**：仅影响 `site/` 目录下的站点配置文件，不涉及任何代码或构建逻辑变更。
- **回迁到 1.4.x 的注意事项**：这是 1.5.2 发版配套的文档维护变更，与 1.4.x 分支无关，无需回迁。
