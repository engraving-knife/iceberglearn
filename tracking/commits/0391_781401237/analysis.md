## 总体目的

本提交是 Iceberg 项目针对 Apache 项目元数据文件 `doap.rdf` 的更新。DOAP（Description of a Project）是 Apache 软件基金会用于描述其孵化和顶级项目的标准 RDF 文件格式，每个 Apache 项目仓库根目录下都维护一份 `doap.rdf`，用于在 `projects.apache.org` 站点上展示项目的最新发布版本信息。

本次修改将 `doap.rdf` 中记录的最新发布版本从 `1.4.0` 更新为 `1.4.3`，并将对应的发布日期从 `2023-10-04` 更新为 `2023-12-27`。这表明 Iceberg 1.4.3 版本已经发布，项目元数据需要同步更新以反映最新的发布状态。

从分支维护视角看，这是一个典型的发布后元数据同步操作。在 1.4.x 维护分支上，已经陆续发布了 1.4.0、1.4.1、1.4.2、1.4.3 等多个版本，而 `doap.rdf` 中只记录最近一次发布，因此每次新版本发布后都需要更新此文件。这类提交通常由发布经理在版本发布流程的最后阶段提交，属于轻量级但必要的元数据维护工作。

## 如何达成设计目的

通过直接修改 `doap.rdf` 文件中的 `<release>` 段落，替换 `<name>`、`<created>`、`<revision>` 三个标签的值，将版本号从 1.4.0 升级到 1.4.3，发布日期更新为 2023-12-27。修改方式简单直接，不涉及任何代码逻辑变更。

## 修改详情

### doap.rdf

**修改目的**：更新 Apache Iceberg 项目的 DOAP 元数据，反映最新发布的 1.4.3 版本信息。

**工作逻辑**：`doap.rdf` 是 RDF/XML 格式的项目描述文件，其中 `<release>` 段落用于声明项目的发布版本。每个 `<Version>` 元素包含三个子元素：
- `<name>`：版本名称，更新为 `1.4.3`
- `<created>`：发布日期，更新为 `2023-12-27`
- `<revision>`：版本修订号，更新为 `1.4.3`

此次修改仅替换了这三个字段的值，从 `1.4.0` / `2023-10-04` / `1.4.0` 改为 `1.4.3` / `2023-12-27` / `1.4.3`。Apache 项目站点会定期抓取各项目的 `doap.rdf` 文件，从而在 projects.apache.org 上展示 Iceberg 的最新发布版本。

## 小结

本提交是一个轻量级的发布元数据同步操作，将 Iceberg 项目的 DOAP 文件从 1.4.0 更新到 1.4.3。这类提交虽然简单，但属于 Apache 项目发布流程的标准化环节，确保外部项目目录站点能够正确展示项目的最新发布状态。从 1.4.x 分支维护角度看，这反映了 1.4.3 版本发布后的收尾工作。
