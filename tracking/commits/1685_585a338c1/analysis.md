## 总体目的

本提交更新 Iceberg 文档站点（基于 MkDocs Material 构建）配置文件 `site/mkdocs.yml` 中用于展示的版本号变量，使其与项目实际依赖的最新版本保持一致。

Iceberg 文档站点在页面中会引用一些外部组件的版本号（例如快速上手示例中让用户安装的 Nessie 版本、Flink 集成示例中使用的 Flink 版本）。这些版本号通过 `mkdocs.yml` 的 `extra` 段定义为全局变量，供文档模板引用。随着项目演进，这些配套组件的推荐版本需要同步更新，否则文档会引导用户使用过旧的版本，造成兼容性问题或示例无法运行。

本次更新把 Nessie 版本从 0.92.1 升到 0.99.0，Flink 版本从 1.19.1 升到 1.20.0、主版本号从 1.19 升到 1.20，同时保留 icebergVersion 为 1.7.1。

## 如何达成设计目的

直接修改 `site/mkdocs.yml` 的 `extra` 段中三个键值对即可。MkDocs 的 `extra` 变量会注入到所有模板上下文中，文档 Markdown 里通过 `{{ nessieVersion }}` 等变量引用，因此改一处即全站生效，无需逐页修改。

### 修改详情

#### site/mkdocs.yml
`extra` 段修改：
- `nessieVersion`: `0.92.1` -> `0.99.0`
- `flinkVersion`: `1.19.1` -> `1.20.0`
- `flinkVersionMajor`: `1.19` -> `1.20`

`icebergVersion` 保持 `1.7.1` 不变。

## 小结

成效：文档站点展示的 Nessie 和 Flink 推荐版本与最新发布对齐，避免引导用户使用过旧版本。影响范围仅限文档站点配置，不影响任何代码、构建或运行时行为。

回迁到 1.4.x 的注意事项：这是文档站点的版本号更新，与 1.4.x 分支基本无关——1.4.x 是较旧的维护分支，其文档站点应展示 1.4.x 对应时期的推荐版本，而非 main 分支的最新版本。因此本提交一般不需要回迁到 1.4.x。如果 1.4.x 也要维护文档站点，应基于 1.4.x 实际兼容的 Nessie/Flink 版本单独决定版本号，而不是直接套用 main 的值（0.99.0 / 1.20.0 对 1.4.x 可能过新而不兼容）。
