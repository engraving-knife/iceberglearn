## 总体目的

更新 Revapi（Reverse API）配置的基准版本从 1.7.0 改为 1.8.0。Revapi 是一个用于检测 API 兼容性变化的工具，Iceberg 项目使用它在构建时检查公共 API 的向后兼容性，确保新版本不会引入破坏性的 API 变更。

在 1.8.0 发布后，API 兼容性检查的基准版本需要更新为 1.8.0，这意味着后续开发中的 API 变更将与 1.8.0 进行比较，而不是之前的 1.7.0。这是版本发布后的标准维护操作。

## 如何达成设计目的

修改 `build.gradle` 中 Revapi 配置的 `oldVersion` 属性，从 `"1.7.0"` 改为 `"1.8.0"`。

## 修改详情

### `build.gradle`（修改, +1/-1 line）

**修改目的**：更新 Revapi API 兼容性检查的基准版本。

**工作逻辑**：在 `subprojects` 块的 `revapi` 配置中，将 `oldVersion = "1.7.0"` 修改为 `oldVersion = "1.8.0"`。Revapi 会将当前代码的公共 API 与指定旧版本的 API 进行比较，检测不兼容的变更（如移除的方法、改变的方法签名等）。

## 小结

- **成效**：Revapi API 兼容性检查的基准版本更新为 1.8.0，后续开发将以此版本为基准进行兼容性检查。
- **影响范围**：仅影响构建配置，不影响项目代码和运行时行为。
- **回迁到 1.4.x 的注意事项**：不建议回迁。1.4.x 分支有自己的版本发布周期，Revapi 基准版本应根据 1.4.x 的实际发布版本设置，而非 1.8.0。此提交属于 1.8.0 发布流程的一部分。
