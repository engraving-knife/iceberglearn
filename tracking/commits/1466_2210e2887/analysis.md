## 总体目的

`doap.rdf`（Description of a Project，RDF 格式）是 Apache 软件基金会（ASF）用于描述各顶级项目的元数据文件，存放在项目仓库根目录。Apache 项目列表站点（`projects.apache.org`）会读取该文件来展示项目的最新发布版本、创建日期、编程语言、分类、仓库地址等信息。每当 Iceberg 发布新版本时，都需要更新 `doap.rdf` 中的 `<release>` 区块，以反映最新的发布版本号和发布日期。

本提交在 Iceberg 1.7.1 发布之际，将 `doap.rdf` 中记录的发布版本从 1.7.0 更新为 1.7.1，并把创建日期从 `2024-11-08` 更新为 `2024-12-06`（1.7.1 的发布日期）。这样 Apache 项目列表站点能正确展示 Iceberg 的最新发布版本为 1.7.1。

## 如何达成设计目的

直接编辑仓库根目录的 `doap.rdf` 文件，将其 `<release>` 区块中 `<Version>` 下的三个子元素（`<name>`、`<created>`、`<revision>`）的值从 1.7.0 对应值替换为 1.7.1 对应值。这是纯元数据文件更新，无代码逻辑。

## 修改详情

### `doap.rdf`

**修改目的**：将 ASF 项目描述文件中的最新发布版本从 1.7.0 更新为 1.7.1。

**工作逻辑**：在 `<release>` → `<Version>` 区块中：
```xml
-        <name>1.7.0</name>
-        <created>2024-11-08</created>
-        <revision>1.7.0</revision>
+        <name>1.7.1</name>
+        <created>2024-12-06</created>
+        <revision>1.7.1</revision>
```
- `<name>`：版本显示名称，从 `1.7.0` 改为 `1.7.1`。
- `<created>`：发布日期，从 `2024-11-08`（1.7.0 发布日）改为 `2024-12-06`（1.7.1 发布日）。
- `<revision>`：版本修订号，从 `1.7.0` 改为 `1.7.1`。

文件其余部分（项目名、描述、主页、邮件列表、编程语言、分类、仓库地址等）保持不变。

## 小结

- **成效**：`doap.rdf` 现记录 Iceberg 最新发布版本为 1.7.1（发布日期 2024-12-06），Apache 项目列表站点将据此展示正确的最新版本信息。
- **影响范围**：仅 `doap.rdf` 一个文件，3 行改动（均为值替换），无代码、构建或运行时逻辑变更。
- **回迁到 1.4.x 的注意事项**：这是项目元数据文件更新，与 1.4.x 版本线无关。1.4.x 是更早的维护分支，其发布版本（如 1.4.x 系列）与 1.7.1 不在同一版本线上。`doap.rdf` 始终只记录最新的发布版本（由 main 分支维护），1.4.x 分支**无需回迁**此变更。即使 1.4.x 分支的 `doap.rdf` 记录的是 1.4.x 的版本，也不应被 main 的 1.7.1 覆盖。
