## 总体目的

本提交是 Iceberg Flink 集成模块（`flink/v1.18`）从 JUnit 4 向 JUnit 5（Jupiter）迁移工程的延续。Iceberg 社区在更早的提交 #9364（commit `6c344dbbb`）中已经创建了 JUnit 5 版本的新基类 `CatalogTestBase`，并迁移了首批 4 个测试类（`TestFlinkCatalogDatabase`、`TestFlinkCatalogTablePartitions`、`TestMetadataTableReadableMetrics` 等），但当时保留了旧 JUnit 4 基类 `FlinkCatalogTestBase` 与新 `CatalogTestBase` 共存，让剩余的测试类仍继承旧基类。本提交完成"剩余清理"：把所有仍继承 `FlinkCatalogTestBase` 的子类（共 8 个测试文件）一次性迁移到继承 `CatalogTestBase`，并删除已无引用的旧基类 `FlinkCatalogTestBase`，标志着 Flink 集成模块测试基础设施的 JUnit 5 迁移基本完成。

新旧两套基类的关键差异体现了 JUnit 4 → 5 的范式转变：(1) **参数化机制**——旧 `FlinkCatalogTestBase` 用 JUnit 4 的 `@RunWith(Parameterized.class)` + 构造函数注入参数（子类必须在构造函数中 `super(catalogName, baseNamespace)` 转发，并在子类构造函数中接收自己的额外参数如 `format`、`isStreamingJob`）；新 `CatalogTestBase` 用 JUnit 5 的 `@ExtendWith(ParameterizedTestExtension.class)` + 字段注入（Iceberg 自定义的 `@Parameter(index=N)` 注解标记字段，框架通过反射按索引注入），子类不再需要写构造函数，只需在字段上加 `@Parameter(index=2)`、`@Parameter(index=3)` 即可接收额外参数。(2) **生命周期注解**——`@Before`/`@After`/`@BeforeClass`/`@AfterClass` 替换为 `@BeforeEach`/`@AfterEach`/`@BeforeAll`/`@AfterAll`，测试方法注解 `@Test` 在参数化测试中替换为 `@TestTemplate`（因为 `@TestTemplate` 让同一个测试方法在参数化上下文中被多次调用，而 `@Test` 在 Jupiter 中只调用一次，与 `ParameterizedTestExtension` 配合时必须用 `@TestTemplate`）。(3) **临时目录**——JUnit 4 的 `@Rule public TemporaryFolder` / `@ClassRule` 替换为 JUnit 5 的 `@TempDir`（字段注入，可以是 `java.nio.file.Path` 或 `File`），且 `@TempDir` 默认字段可见性要求宽松（本提交把 `TestBase` 中的 `@TempDir Path temporaryDirectory` 从 package-private 改为 `protected`，让子类 `TestStreamScanSql` 能访问到基类的临时目录用于 `GenericAppenderHelper`）。(4) **断言**——`org.junit.Assert.assertEquals` / `Assert.assertNull` / `Assert.assertTrue` 替换为 AssertJ 流式断言 `assertThat(actual).isEqualTo(expected)` / `assertThat(x).isNull()` / `assertThat(x).isPresent()`，断言描述通过 `.as("...")` 链式调用而非方法首参传入；`org.junit.Assume.assumeFalse` 替换为 AssertJ 的 `org.assertj.core.api.Assumptions.assumeThat(x).isFalse()`（注意是 `Assumptions` 而非 `Assertions`，前置假设失败时跳过测试而非报错）。(5) **MiniCluster 资源**——JUnit 4 的 `@ClassRule public static final MiniClusterWithClientResource MINI_CLUSTER_RESOURCE` 在子类中重复声明，JUnit 5 中改由基类 `TestBase` 通过 `MiniClusterExtension`（Jupiter Extension 模型）统一提供，子类直接删除 `@ClassRule` 字段，避免资源重复创建。

配套地，本提交还连带把 `TestFlinkHiveCatalog`、`TestIcebergConnector`、`TestFlinkCatalogTablePartitions` 中对 `FlinkCatalogTestBase` 的静态方法引用（`FlinkCatalogTestBase.getURI(hiveConf)`、`FlinkCatalogTestBase.toWithClause(props)`、`FlinkCatalogTestBase.parameters()`）改为 `CatalogTestBase` 上的同名静态方法引用——因为 `CatalogTestBase` 在创建时已经把这些工具方法（`getURI`、`toWithClause`、`parameters`）从旧基类复制过来，旧基类删除后这些引用必须改指向新基类。这一连串引用更新是删除旧基类的前置条件。

## 如何达成设计目的

迁移遵循固定的"7 步替换"模式，对每个测试类机械执行：(1) 删除 `import org.junit.*`（`After`/`Before`/`Test`/`Assume`/`Assert`/`ClassRule`/`Rule`/`RunWith`/`Parameterized`/`TemporaryFolder`），新增 `import org.junit.jupiter.api.AfterEach`/`BeforeEach`/`TestTemplate`（部分文件还需 `import org.junit.jupiter.api.io.TempDir`）；断言改 `import static org.assertj.core.api.Assertions.assertThat` / `AssertionsForClassTypes.assertThatThrownBy`，前置假设改 `import static org.assertj.core.api.Assumptions.assumeThat`。(2) 新增 `import org.apache.iceberg.Parameter` / `org.apache.iceberg.Parameters`——这是 Iceberg 自定义的 JUnit 5 参数化注解（位于 `org.apache.iceberg` 包），与 `ParameterizedTestExtension` 配合工作。(3) 类签名去掉 `@RunWith(Parameterized.class)` 注解（基类已 `@ExtendWith(ParameterizedTestExtension.class)`，子类继承即可），父类从 `FlinkCatalogTestBase` 改为 `CatalogTestBase`。(4) 删除子类构造函数（不再需要 `super(catalogName, baseNamespace)` 转发），把原本通过构造函数传入的额外参数（如 `format`、`isStreamingJob`、`isPartition`）改为 `@Parameter(index=N)` 注解标记的字段——`index=0` 与 `index=1` 在基类已定义为 `catalogName` 与 `baseNamespace`，子类额外参数从 `index=2` 起递增。(5) `@Parameterized.Parameters` 注解改为 `@Parameters`，返回类型 `Iterable<Object[]>` 改为 `List<Object[]>`，方法体中 `FlinkCatalogTestBase.parameters()` 调用改为 `CatalogTestBase.parameters()`。(6) `@Before`→`@BeforeEach`，`@After`→`@AfterEach`，`@Test`→`@TestTemplate`（在参数化测试类中）。(7) 删除 `@ClassRule public static final MiniClusterWithClientResource` 与 `@ClassRule public static final TemporaryFolder` 字段（基类已通过 `MiniClusterExtension` 与 `@TempDir` 提供）；`@Rule public TemporaryFolder temp` 改为 `@TempDir Path temp`（或 `File`）。同时所有 `Assert.assertEquals("msg", expected, actual)` 改为 `assertThat(actual).as("msg").isEqualTo(expected)`，`Assert.assertTrue("msg", cond)` 改为 `assertThat(cond).as("msg").isTrue()`，`Assert.assertNull("msg", x)` 改为 `assertThat(x).as("msg").isNull()`，`Assume.assumeFalse("msg", cond)` 改为 `assumeThat(cond).as("msg").isFalse()`。

### `flink/v1.18/flink/src/test/java/org/apache/iceberg/flink/FlinkCatalogTestBase.java`（删除，155 行）

**修改目的**：删除旧的 JUnit 4 抽象测试基类，因为所有子类已迁移到新的 `CatalogTestBase`，旧基类无引用。

**工作逻辑**：该文件原是 JUnit 4 风格的参数化测试基类：`@RunWith(Parameterized.class) public abstract class FlinkCatalogTestBase extends FlinkTestBase`，通过构造函数接收 `catalogName` 与 `baseNamespace` 两个参数，`@BeforeClass createWarehouse()` / `@AfterClass dropWarehouse()` 管理 hive 与 hadoop 两个 `TemporaryFolder` 仓库目录，`@Before before()` 执行 `sql("CREATE CATALOG %s WITH %s", ...)`，`@After clean()` 执行 `dropCatalog(catalogName, true)`，`@Parameterized.Parameters(name = "catalogName = {0} baseNamespace = {1}") parameters()` 提供三组参数（`testhive`+empty namespace、`testhadoop`+empty namespace、`testhadoop_basenamespace`+`Namespace.of("l0","l1")`），并持有 `validationCatalog`、`validationNamespaceCatalog`、`config`、`flinkDatabase`、`icebergNamespace`、`isHadoopCatalog` 等字段与 `warehouseRoot()`、`getFullQualifiedTableName()`、`getURI(HiveConf)`、`toWithClause(Map)` 等工具方法。这些字段与方法在 `CatalogTestBase`（commit `6c344dbbb` 创建）中均已等价实现（且改为 JUnit 5 风格：`@TempDir File hiveWarehouse` / `hadoopWarehouse` 替代 `TemporaryFolder`，`@BeforeEach`/`@AfterEach` 替代 `@Before`/`@After`，`@Parameter(index=0/1)` 字段注入替代构造函数），故旧基类可以安全删除。

### `flink/v1.18/flink/src/test/java/org/apache/iceberg/flink/TestBase.java`

**修改目的**：把 `@TempDir Path temporaryDirectory` 字段从 package-private 改为 `protected`，让子类（如 `TestStreamScanSql`）能访问该临时目录。

**工作逻辑**：单行修改 `@TempDir Path temporaryDirectory;` → `@TempDir protected Path temporaryDirectory;`。`TestStreamScanSql` 原本用 `TEMPORARY_FOLDER`（继承自旧基类的 `@ClassRule public static final TemporaryFolder`）构造 `GenericAppenderHelper(table, FORMAT, TEMPORARY_FOLDER)`，迁移后改用基类 `TestBase` 的 `@TempDir Path temporaryDirectory`，但该字段原本是 package-private，跨包子类 `org.apache.iceberg.flink.source.TestStreamScanSql`（在 `source` 子包）无法访问，故提升为 `protected`。这是 JUnit 5 `@TempDir` 字段注入机制下的一个连带调整——旧 `TemporaryFolder` 是 `@ClassRule public static final`，跨包可访问；新 `@TempDir` 是实例字段，必须显式提升可见性。

## 小结

本次提交完成 Iceberg Flink 1.18 集成模块从 JUnit 4 向 JUnit 5 迁移的"剩余清理"工作，把 8 个仍继承 `FlinkCatalogTestBase` 的测试子类（`TestFlinkCatalogTable`、`TestFlinkTableSink`、`TestFlinkUpsert`、`TestRewriteDataFilesAction`、`TestFlinkMetaDataTable`、`TestStreamScanSql` 等）一次性迁移到继承 `CatalogTestBase`（commit `6c344dbbb` 创建的 JUnit 5 等价基类），并删除已无引用的旧基类 `FlinkCatalogTestBase`。迁移严格遵循"7 步替换"模式：(1) import 替换（`org.junit.*` → `org.junit.jupiter.api.*` + AssertJ + Iceberg `Parameter`/`Parameters`）；(2) 类签名去 `@RunWith(Parameterized.class)`，父类改 `CatalogTestBase`；(3) 删除构造函数，改为 `@Parameter(index=N)` 字段注入（基类 index=0/1，子类从 index=2 起递增）；(4) `@Parameterized.Parameters` → `@Parameters`，`Iterable` → `List`，`FlinkCatalogTestBase.parameters()` → `CatalogTestBase.parameters()`；(5) `@Before`/`@After`/`@Test` → `@BeforeEach`/`@AfterEach`/`@TestTemplate`；(6) 删除 `@ClassRule MiniClusterWithClientResource` 与 `@ClassRule TemporaryFolder`（基类已通过 `MiniClusterExtension` 与 `@TempDir` 提供），`@Rule TemporaryFolder` → `@TempDir Path`；(7) `Assert.assertEquals`/`assertNull`/`assertTrue` → AssertJ `assertThat(...).isEqualTo(...)`/`.isNull()`/`.isTrue()`，`Assume.assumeFalse` → `Assumptions.assumeThat(...).isFalse()`。连带修改包括：`TestBase.temporaryDirectory` 字段提升为 `protected`（让跨包子类 `TestStreamScanSql` 能访问 `@TempDir` 字段，因 JUnit 5 字段注入默认是 package-private 不可跨包访问）；`TestFlinkHiveCatalog`、`TestIcebergConnector`、`TestFlinkCatalogTablePartitions` 中对 `FlinkCatalogTestBase.getURI/toWithClause/parameters` 静态方法的引用全部改为 `CatalogTestBase` 同名方法。本次迁移标志着 Flink 集成模块测试基础设施的 JUnit 5 化基本完成，旧基类彻底退出历史舞台。
